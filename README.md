# LibraryAPP
Приложение «Книжный магазин» — интерактивная игра-симулятор управления книжным магазином, разработанная с использованием объектно-ориентированного программирования и архитектуры Windows Forms.
Цель игры: Успешно пережить игровой день (5 минут), обслуживая покупателей, проверяя поставки и управляя балансом магазина, не допустив проигрыша по одному из условий.

## Основные возможности

### Управление книгами
- **Заказ книг** — Ручное добавление книг с указанием названия, автора, жанра, страниц и цены
- **Генерация книг** — Случайная генерация книг из базы данных с проверкой уникальности
- **Сиквелы** — Автоматическое добавление суффиксов («Бесы» → «Бесы 2») при дублировании названия и автора
- **Поиск** — Поиск книг по ID или названию с отображением результатов

### Система покупателей
- Покупатели приходят раз в m секунд
- Типы запросов:
  - Конкретная книга: «Хочу "Бесы" Достоевского»
  - Жанр: «Хочу книгу в жанре "Фэнтези"»
- Правила продажи:
  - Цена продажи ≤ базовая цена × 1.15 (макс. наценка 15%)
  - Книга должна соответствовать запросу
- Реакция:
  - Доволен → покупка совершена, прибыль зачислена
  - Недоволен → уходит, счётчик недовольных +1

### Система поставок
- Поставки приходят раз в n секунд
- Заказанные книги (вкладка "Заказать книгу") — Всегда корректные, цена фиксируется при заказе
- Случайные поставки (вкладка "Поставки"):
  - Появляются автоматически
  - Могут содержать ошибки:
    - Плагиат — название есть в БД, но автор другой
    - Опечатка — автор есть в БД, но название искажено
  - Требуют проверки администратором (игроком)
- Награды и штрафы:
  - Правильно определил ошибку → +100 ₽ бонус
  - Пропустил ошибку → -150 ₽ штраф

### Режимы сложности

**Лёгкий режим:**
- Покупатели: каждые 20 сек
- Поставки: каждые 30 сек
- Лимит очереди покупателей: 10
- Лимит очереди поставок: 15
- Макс. недовольных клиентов: 5

**Средний режим:**
- Покупатели: каждые 15 сек
- Поставки: каждые 20 сек
- Лимит очереди покупателей: 8
- Лимит очереди поставок: 10
- Макс. недовольных клиентов: 3

**Сложный режим:**
- Покупатели: каждые 8 сек
- Поставки: каждые 10 сек
- Лимит очереди покупателей: 6
- Лимит очереди поставок: 8
- Макс. недовольных клиентов: 1

### Условия победы и поражения

**ПОБЕДА:**
- Пережить игровой день (300 секунд)
- Не исчерпать баланс магазина
- Не превысить лимиты очереди и недовольных клиентов

**ПОРАЖЕНИЕ:**
- Переполненная очередь покупателей
- Слишком много недовольных клиентов
- Банкротство (баланс ≤ 0)
- Переполненная очередь поставок

## Как запустить
### Через Visual Studio
1. Откройте файл `LibraryAPP.sln`
2. Убедитесь, что стартовым проектом установлен WinForms
3. Нажмите `Ctrl + F5` (`Ctrl + Fn + F5`) для запуска без отладки
4. Откроется главное меню игры

## Особенности программы
1. Многоуровневая валидация: проверка на уровне формы + исключения в библиотеке
2. User-friendly интерфейс
4. Тестировалось на операционной системе Windows 10/11

## Требования
1. .NET 10.0 или новее
2. Visual Studio 2019+ (или любая среда с поддержкой C# и WinForms)
3. Операционная система Windows 10+
