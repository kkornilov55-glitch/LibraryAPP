# LibraryAPP
Приложение «Книжный магазин» — интерфейс на Windows Forms для управления коллекцией книг с использованием объектно-ориентированного подхода.

## Функционал
- Добавление книг: вручную или через случайную генерацию
- Организация по жанрам: книги одного жанра хранятся в отдельном шкафу с ограниченной вместимостью
- Поиск книг: по идентификационному номеру (ID) или по названию
- Продажа книг: с автоматическим обновлением баланса магазина и освобождением места в шкафу
- Перепрофилирование шкафов: при достижении лимита шкафов можно распродать целый жанр и освободить место для нового
- Валидация данных: проверка обязательных полей, корректности числовых значений, обработка ошибок
- Unit-тестирование: 40 тестов с покрытием 91% бизнес-логики

## Как запустить
### Через Visual Studio
1. Откройте файл `LibraryAPP.sln`
2. Убедитесь, что стартовым проектом установлен WinForms
3. Нажмите `Ctrl + F5` (`Ctrl + Fn + F5`) для запуска без отладки
4. Приложение откроется с двумя вкладками: «Новая книга» и «Магазин»

## Особенности программы
1. Многоуровневая валидация: проверка на уровне формы + исключения в библиотеке
2. User-friendly интерфейс
3. Умная генерация названий: при дублировании добавляется цифровой суффикс («Айсберг» → «Айсберг 2» → «Айсберг 3»)

## Требования
1. .NET 10.0 или новее
2. Visual Studio 2019+ (или любая среда с поддержкой C# и WinForms)
